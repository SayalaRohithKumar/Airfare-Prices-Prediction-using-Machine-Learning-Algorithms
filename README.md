# Airfare-Prices-Prediction-using-Machine-Learning-Algorithms
Airfare Prices Prediction Using Machine Learning, engineered an end-to-end ML pipeline analyzing 10,000+ flight records. Evaluated 8 algorithms (Random Forest, SVR, MLP Neural Networks) with feature engineering, achieving R²≈0.85. Deployed a Tkinter GUI, proving expertise in Python, Pandas, and Scikit-learn.
